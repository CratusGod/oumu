# Matugen template

`colors.json` is the template behind Oumu's **Matugen** theme. You don't need to copy it by hand:
**Settings → Appearance → Theme → Matugen → Set up matugen** installs and registers it. Ryoku needs
no set-up at all. The full instructions are in [`docs/THEMES.md`](../../docs/THEMES.md).
